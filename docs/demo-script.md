# 两分钟演示录制脚本

1. **0:00–0:15**：展示 README 架构图和 `docker compose ps` 三个健康服务。
2. **0:15–0:35**：管理员上传一份 Markdown，展示 `pending → processing → ready`。
3. **0:35–1:00**：研发账号询问“生产发布的灰度流程”，展示流式回答、引用和耗时。
4. **1:00–1:20**：研发账号查看文档列表，证明没有财务报销制度；切换财务账号展示相反结果。
5. **1:20–1:35**：询问“食堂今天吃什么”，展示证据不足拒答。
6. **1:35–1:55**：运行 `docker compose exec api python -m scripts.evaluate`，展示 100% Recall@5、90% 单文档 Hit@1、80% 拒答率和零越权。
7. **1:55–2:00**：回到架构图，总结权限先于检索、引用可追溯、指标可复现。

Windows 可使用截图工具的屏幕录制功能。录制完成后保存为 `docs/demo.mp4`，并在 README 顶部添加视频链接；不要提交包含真实 API Key 或敏感文档的画面。
